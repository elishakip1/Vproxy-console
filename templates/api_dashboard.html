Authentication

Base URL:

{{ base_url }}

Send your key in every request with either header:

X-API-Key: vpx_your_key
Authorization: Bearer vpx_your_key

Proxies use the format host:port:user:pass.

POST/api/v1/check

Checks proxies the same way as the web checker (IP stability, fraud score, used and bad caches) and returns the good ones. It stops as soon as it finds target_good good proxies.

{% if current_user.is_admin %}{% endif %}
FieldTypeNotes
proxiesarray of stringsRequired. Up to {{ max_paste }} are checked; extra are ignored.
target_goodintOptional, 0–100. Stop after this many good proxies. 0 = check every proxy. Default {{ stop_after }}.
max_scoreintOptional, 0–100. Reject proxies scoring above this. Defaults to your saved score ({{ my_max_score if my_max_score is not none else default_score }}).
verboseboolOptional. Also return every checked proxy in results.
strictboolAdmins only. Default true.
 
curl -X POST {{ base_url }}/api/v1/check \
  -H "X-API-Key: vpx_your_key" \
  -H "Content-Type: application/json" \
  -d '{"proxies": ["1.2.3.4:8000:user:pass", "5.6.7.8:8000:user:pass"], "target_good": 2, "max_score": 10}'

Response

{
  "status": "success",
  "good": [
    {"proxy": "1.2.3.4:8000:user:pass", "ip": "203.0.113.7", "status": "success", "score": 0,
     "geo": {"country_code": "US", "state": "Washington", "city": "Seattle", "postcode": "98101"}}
  ],
  "stats": {"submitted": 2, "checked": 2, "api": 2, "used": 0, "bad": 0,
            "unstable": 0, "error": 0, "invalid_format": 0, "truncated_to": {{ max_paste }}},
  "max_score": 10
}

Result statuses: success, bad_score, used_cache, bad_cache, unstable_ip, error. Checks take a few seconds per proxy, so smaller batches return faster.

POST/api/v1/mark-used

Marks a proxy as used so it won't be returned again.

curl -X POST {{ base_url }}/api/v1/mark-used \
  -H "X-API-Key: vpx_your_key" \
  -H "Content-Type: application/json" \
  -d '{"proxy": "1.2.3.4:8000:user:pass", "ip": "203.0.113.7"}'
{"status": "success"}

Python example
import requests

API = "{{ base_url }}/api/v1"
HEADERS = {"X-API-Key": "vpx_your_key"}

proxies = open("proxies.txt").read().splitlines()
r = requests.post(f"{API}/check", json={"proxies": proxies, "target_good": 2},
                  headers=HEADERS, timeout=120)
data = r.json()

for p in data.get("good", []):
    print(p["proxy"], p["ip"], p["score"], p["geo"].get("country_code"))
    requests.post(f"{API}/mark-used", json={"proxy": p["proxy"], "ip": p["ip"]}, headers=HEADERS)
